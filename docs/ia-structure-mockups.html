01Die Diagnose

The single page repeats a small set of brand messages across ~10 sections with almost no division of labour: the same four ideas — "circular / one-of-one from clothing that already exists," "you design, AI only sorts + makes," "made for one, no overproduction," and the "most fashion starts with production, ours with people" reversal — each recur 4–7 times in near-identical wording. The problem is BOTH: heavy verbatim repetition (the tagline "Made for one. Not for all." lives in hero, loop stage 4, sphere detail, plus schema; the "millions produced before anyone asks" line is duplicated almost word-for-word between own.text and the manifesto/urcreate framing) AND dispersion (privacy "100% client-side" is stated in 5 different places; the pre-launch / "be first" disclaimer is scattered across faq, export, est, footer with no single canonical home). The landing stack (manifesto → facts → loop → ai-done-right → your-style → how → finale) is essentially six sequential restatements of one thesis before the studio even opens, so the user reads the same promise repeatedly instead of it being contained in one authoritative place per idea. Recommendation: designate one canonical section per theme (loop = circular story, ai-done-right = human-vs-AI boundary, facts = the problem, a single footnote/FAQ = pre-launch+privacy) and demote the echoes to short cross-references. Evidence is from js/i18n.js (authoritative copy) and index.html section structure.
